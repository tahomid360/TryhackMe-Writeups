## 📋 What I Learned

1. **System Configuration (msconfig)** - Boot options, Services, Startup management
2. **Computer Management (compmgmt.msc)** - System Tools, Storage, Services
3. **Event Viewer (eventvwr.msc)** - Windows Logs (Application, Security, System)
4. **Local Users and Groups (lusrmgr.msc)** - Creating and managing users & groups
5. **Performance Monitor (perfmon.msc)** - System performance tracking
6. **Device Manager (devmgmt.msc)** - Driver management
7. **Task Scheduler (taskschd.msc)** - Automating tasks
8. **Registry Editor (regedit)** - Windows registry basics

---

## ⚠️ Problems I Faced

| Problem | Solution |
|---------|----------|
| lusrmgr.msc didn't work (Windows Home edition) | Used Computer Management instead to manage users |
| Event Viewer had too many logs | Applied filter to show only Errors and Warnings |
